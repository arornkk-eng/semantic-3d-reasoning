# ZipSplat-Demo 项目总体方案（优化版）

## 1. 项目定位

本项目基于 **ZipSplat + 3D Gaussian
Splatting**，实现从多视角图片输入到轻量化三维场景重建，并通过 Web
端实现实时 360°交互浏览。

项目重点：

-   ZipSplat快速生成3D Gaussian模型
-   Gaussian模型轻量化优化
-   Web端实时可视化展示
-   提供模型信息统计与交互界面

# 4. 功能模块设计

## 4.1 图片输入模块

输入：

    images/

    001.jpg
    002.jpg
    003.jpg
    ...

要求：

-   多视角
-   覆盖目标物体不同角度
-   图片质量稳定

------------------------------------------------------------------------

## 4.2 ZipSplat重建模块

功能：

将多视角图片转换为3D Gaussian表示。

输出：

    scene.ply

包含：

-   xyz位置
-   rotation
-   scale
-   color
-   opacity

------------------------------------------------------------------------

## 4.3 Gaussian优化模块（重点）

目标：

降低网页渲染压力。

优化方式：

-   删除低opacity Gaussian
-   删除贡献较小点
-   控制Gaussian数量

目标：

    百万级Gaussian

    ↓

    数万级Gaussian

提升：

-   加载速度
-   FPS
-   Web交互体验

------------------------------------------------------------------------

## 4.4 Web Viewer模块

功能：

-   3D模型加载
-   鼠标旋转
-   缩放
-   平移
-   实时浏览

技术：

-   viser
-   WebGL
-   Gaussian Renderer

目标：

实现类似：

    Gaussian(PLY)
    +
    OBJ Model

的在线展示效果。
